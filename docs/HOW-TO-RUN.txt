Aegis - manual start (works with any Windows, no PowerShell needed)
===================================================================

OFFLINE EDITION: if this package contains runtime\python314\python.exe, you need
NOTHING installed - no Python, no network. Just double-click run.bat. Everything
below applies to the normal edition only.

Requirements: Windows 10/11, Python 3.11 - 3.14 (tested on 3.14.6).
First run needs internet to install dependencies.

First, a safe dry check (installs nothing, changes nothing):

    run.bat -DryRun

It reports: which Python it found, whether .venv exists, whether dependencies
are installed, whether .env/seed data exist, and the exact command it would run.

Steps (run these in this folder, one by one):

  1) python -m venv .venv

  2) .venv\Scripts\python.exe -m pip install -r requirements.txt

     If the default index is slow, use a mirror:
     .venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

  3) copy .env.example .env
     (optional: open .env and fill DEEPSEEK_API_KEY to actually run LLM workflows.
      Without a key you can still browse the 10 recorded traces and run offline tests.)

  4) .venv\Scripts\python.exe scripts\setup_demo_data.py

     This installs the demo dataset: 10 real runs and their output files.
     After this, open these URLs to see real evidence:
       http://127.0.0.1:8507/?trace=43d6b6a9   (data pipeline, all green)
       http://127.0.0.1:8507/?trace=43cbcac1   (circuit breaker -> human -> third try)

  5) .venv\Scripts\python.exe -m streamlit run app.py --server.port 8507 --server.address 127.0.0.1

  Then open http://127.0.0.1:8507 in a browser. Close the window to stop.

Offline self-check (no network, no API key):

  .venv\Scripts\python.exe scripts\verify\verify_env.py --with-tests
      Expect: "160 tests ... OK", demo traces present, port free.

  .venv\Scripts\python.exe scripts\verify\verify_matrix.py
      Expect: "14/14 passed"

Just want to see the deliverables (no Python at all):
  docs\方案书.pdf                        (proposal, 27 pages)
  docs\Aegis-赛道一-方案讲解.pptx         (slides, 16 pages)
  docs\Aegis-演示视频.mp4                 (demo video, 3:04, subtitles burned in)

Troubleshooting:
  - "python is not recognized": install Python and tick "Add python.exe to PATH".
  - Port 8507 busy: close the old instance, or start with --server.port 8508.
  - "engine not started - an engine is already running": a stale process holds the
    single-writer lease. Close old windows/processes and retry.
  - Excel workflow (excel_report) needs: .venv\Scripts\python.exe -m pip install openpyxl
