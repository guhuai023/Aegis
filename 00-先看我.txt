【这个包要不要装 Python？】
  看根目录有没有 runtime\python314\
    有   → 离线版：内部已带 Python 3.14.6 与全部依赖，不装 Python、不联网，双击 run.bat 即可
    没有 → 常规版：需要 Python 3.11~3.14，首次启动联网装约 60 MB 依赖（脚本内置清华镜像重试）

【四个最常见的问题】
  双击 run.bat 闪退 ....... 装 Python 3.11+ 并勾选 "Add python.exe to PATH"；或改用离线版
  「已有引擎在运行」...... 上次进程没退干净（引擎有单写者租约），关掉旧窗口后重开
  启动任务报 Key 错误 ..... .env 里没填 DEEPSEEK_API_KEY；看演示数据、跑单测不受影响
  8507 端口被占用 ........ 关掉占用进程，或改用 --server.port 8508

【我们明确写出来的限制（不是隐瞒）】
  · 真跑结果不是逐字节确定：大模型有随机性，可复现的是流程形态与验收结论，不是每句话
  · 没有向量检索（RAG）：DeepSeek 未提供 embedding 接口
  · 沙箱是进程级（子进程 + 独立 venv + 工作区隔离），不是容器级
  · 画布不是自由拖拽编辑器：它是 YAML 的可视化入口，不支持拖拽连线
  · sub_workflow 子工作流节点未实现：YAML 里写了会显式报错，不会静默跳过
  · 没有 CI / Dockerfile：以 run.bat + verify_env.py 替代

【这个包是怎么被验证过的】
  打包脚本每次都会：逐文件算 SHA256 写进 MANIFEST.txt → 解压到临时干净目录 →
  跑 verify_env.py --with-tests 与 verify_matrix.py → 装演示数据并核对 trace/日志/交付文件数 →
  检查 run.bat 纯 ASCII、run.ps1 带 BOM 并实跑 run.bat -DryRun。
  任何一项不过就不出包，所以你解压看到的，就是被验证过的那一份。
